# Darwin Cable Works

Darwin Cable Works provides data cabling, networking and practical IT support for homes and businesses in Darwin, Palmerston, Howard Springs, Humpty Doo and Berry Springs.

## Services

- Data and structured cabling, including data points
- Wi-Fi and wireless access point setup
- Network equipment installation and connectivity
- Antenna and MATV services
- POS and docket system connectivity
- Basic IT setup and troubleshooting
